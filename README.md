DocWise is an AI-powered mobile document assistant built with Flutter, Firebase and Gemini.

It helps users understand complex PDFs and images by generating clear summaries, highlighting important information, identifying risks, and allowing users to chat with their documents.

## Key Features

- Analyse PDFs up to 50 pages
- Camera and gallery document scanning
- AI-powered summaries and important points
- Risk and document health analysis
- Chat with Document
- English, Hindi and Gujarati support
- Light and Dark mode
- Multi-page preview, reorder and delete
- Persistent history and settings
- Secure Firebase Functions backend for Gemini API access

## Tech Stack

- Flutter
- Dart
- Firebase
- Google Gemini API
- Firebase Functions
- REST APIs
- Android

## Performance

- Large PDFs processed through Gemini Files API
- 48-page PDF tested in approximately 18 seconds
- Optimised inline processing for smaller image sets
